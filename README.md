# Дача

Каталог загородных домов недалеко от Москвы: реальные фотографии, категории размещения, сравнение до трёх вариантов, избранное, отдельная карта и переходы на официальные сайты объектов.

**Сайт:** https://deantipin.github.io/dacha/

## Что опубликовано

Это статическая версия интерфейса на React и Vite для GitHub Pages. В репозитории — публичный снимок каталога от 13 ноября 2026 года: 23 места, 33 категории и 77 фотографий. Дата проверки характеристик указана в интерфейсе. Источники фотографий доступны в галерее; права на фотографии принадлежат их владельцам.

Каталог загружается из `data/public-catalog.json`, а поиск по характеристикам работает в браузере. Страница не обращается к API каталога или системам бронирования и не запускает сбор данных. Актуальные цены, доступность, вместимость и правила размещения детей нужно проверять на сайте объекта. Даты и гости передаются в проверенные ссылки Ambient Park и Domingo Dacha; для остальных объектов открывается официальная ссылка без выдуманных параметров.

Избранное и сравнение сохраняются в локальном хранилище браузера. При открытии карты подложка загружается с OpenStreetMap. Для шрифта используется Google Fonts. Фотографии и Leaflet размещены вместе с сайтом.

Исходный сервис с серверной частью остаётся на [Sites](https://weekend-houses-denis.villavideoteam.chatgpt.site). Его база данных, защищённые обработчики и ограничители запросов не включены в этот репозиторий. GitHub Pages не поддерживает такую серверную часть; эта копия к ней не подключена.

## Локальный запуск

Нужен Node.js 22.13 или новее.

```sh
npm ci
npm run dev
```

Открыть адрес Vite с путём `/dacha/`, например `http://127.0.0.1:5173/dacha/`.

```sh
npm test
npm run build
npm run preview
```

Сборка находится в `dist/`. По умолчанию все локальные ресурсы используют базовый путь `/dacha/`. Для другого расположения:

```sh
npm run build -- --base=/another-path/
```

## Обновление и публикация

GitHub Actions проверяет тесты и типы, собирает сайт и публикует `dist/` в GitHub Pages после обновления ветки `main`. В настройках репозитория Pages должен быть выбран источник **GitHub Actions**. Секреты для этой публикации не нужны: используется встроенный `GITHUB_TOKEN` с доступом только к репозиторию и Pages.

Чтобы обновить данные, заменить `data/public-catalog.json` новым проверенным публичным снимком и добавить соответствующие изображения в `public/photos/`, затем выполнить проверки и отправить изменения в `main`. Сырые исследования, приватные базы, персональные данные и токены публиковать не нужно.
